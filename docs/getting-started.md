# Getting Started

Welcome to the Nightflow Test Documentation repository.

## Overview

This documentation covers the basics of using the Nightflow platform for knowledge management.

## Prerequisites

Before you begin, ensure you have:

- A Nightflow account
- Access to the admin dashboard
- Basic understanding of knowledge sources

## Quick Start

1. Navigate to Settings > Projects
2. Click "Create Project"
3. Select your source type (GitHub, Google Drive, etc.)
4. Configure the connection
5. Wait for indexing to complete
